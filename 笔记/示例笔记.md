# 示例笔记

这是一篇示例笔记，用来确认「保存即自动同步」是否正常工作。

## 怎么用

1. 在这个文件夹里新建 `.md` 文件（可以放在子文件夹里，比如现在这个 `笔记/` 目录）。
2. 正常写内容，`Ctrl + S` 保存。
3. 大约 8 秒后，改动会自动 commit 并 push 到 <https://github.com/Zfeng08/Illustrated_skill>。
4. 刷新 GitHub 页面就能看到。

## 小技巧

- 文件名和内容都可以用中文。
- 图片、附件也可以直接拖进这个文件夹，一样会自动上传。
- 删掉文件也会同步（GitHub 上对应文件会被删除）。
- 万一没同步，看一眼日志：`.autosync\logs\autosync.log`。
